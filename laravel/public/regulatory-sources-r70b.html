02 · AKUISISI TERKONTROL

Cara mengambil naskah lengkap

Di komputer Windows tempat PI dipasang, jalankan berkas berikut. Pengunduhan hanya dari alamat JDIH yang terdaftar, tanpa menulis ke basis data produksi.

  1. Tutup PI apabila sedang digunakan; tidak perlu mengubah akun atau langganan FREE.
  2. Buka folder aplikasi PI R69E dan klik dua kali SINKRONKAN-SUMBER-RESMI-PI-R70B.cmd.
  3. Tunggu tiap dokumen selesai; untuk lampiran APBD yang panjang proses dapat berlangsung beberapa menit.
  4. Lihat status baru pada halaman ini setelah penyegaran. Jika masih Perlu review, periksa keluaran terminal.

Tidak ada tombol sinkronisasi melalui web: proses akuisisi dilakukan lokal secara eksplisit. Versi sebelumnya tetap disimpan sebagai bukti historis.

03 · REVIEW GATE

Batas simpulan mesin

  • Periksa identitas, struktur, pasal, lampiran, dan status berlaku dari setiap naskah resmi.
  • Bandingkan perubahan pertama sampai kelima dengan naskah dasar sebelum menyusun versi terkonsolidasi.
  • Ketidaksesuaian metadata JDIH ditandai untuk investigasi, bukan disimpulkan sebagai kesalahan hukum.
  • Audit disharmoni vertikal/horizontal dan angka APBD tetap ditahan sampai bukti serta gerbang review lengkap.
