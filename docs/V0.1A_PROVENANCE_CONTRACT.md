# V0.1A Provenance-First Ingestion Contract

## Tujuan tahap ini

V0.1A tidak membuat AI membaca dokumen. Tahap ini membuat Planning Intelligence
memiliki "ingatan sumber" sendiri yang tetap ada walaupun model AI diganti.

Capability permanen yang ditambahkan:

1. Satu dokumen dapat mempunyai banyak versi file yang tidak saling menimpa.
2. Setiap versi memiliki checksum SHA-256 sendiri.
3. Setiap proses parsing kelak mempunyai identitas parser, versi parser,
   konfigurasi, fingerprint, status, dan hasil.
4. Hasil parsing akan dipecah menjadi source unit yang dapat ditunjuk ulang,
   misalnya halaman, heading, paragraf, daftar, tabel, baris, atau sel.
5. Setiap source unit membawa lokasi, urutan, struktur, isi, dan checksum.
6. Tabel evidence dapat menunjuk ke document version dan source unit secara
   langsung.

## Pembagian tanggung jawab

### Document
Identitas logis dokumen, misalnya "RKPD Kota X 2027".

### Document Version
Satu file fisik tertentu dari dokumen tersebut. Tidak boleh berubah setelah
tercatat. Parsing selalu mengacu ke versi ini.

### Parsing Run
Catatan satu eksekusi parser tertentu terhadap satu Document Version. Dengan
ini sistem dapat mengetahui parser apa yang menghasilkan struktur tertentu.

### Source Unit
Unit sumber terkecil yang dapat dijadikan bukti dan dikutip kembali.

### Evidence
Objek bukti yang nantinya dipakai analisis/finding dan dapat menunjuk persis
ke Document Version + Source Unit.

## Prinsip kontrol

- Tidak ada ketergantungan OpenAI, Claude, Gemini, atau provider AI lain.
- Existing V0.0 Document tetap dipertahankan agar UI lama tidak rusak.
- File lama dibackfill menjadi Document Version 1 tanpa mengubah file sumber.
- Upload dokumen baru otomatis menghasilkan Document Version 1.
- Versi baru pada dokumen yang sama mendapat nomor berurutan.
- File identik pada dokumen yang sama tidak dibuat menjadi versi duplikat.
- Semua parsing berikutnya wajib mengacu pada Document Version, bukan pada
  kolom file mutable di tabel Document.
- Source Unit harus reproducible dan memiliki fingerprint/checksum.

## Traceability target

Finding
  -> Evidence
  -> Source Unit
  -> Parsing Run
  -> Document Version
  -> Document
  -> file + checksum + page/locator

Ini adalah jalur bukti minimum yang harus dipertahankan pada tahap-tahap
Planning Intelligence berikutnya.
